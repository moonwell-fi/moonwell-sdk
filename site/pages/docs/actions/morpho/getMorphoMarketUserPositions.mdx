# getMorphoMarketUserPositions

Retrieves all active positions for a specific user across Morpho markets, including their supplied and borrowed assets, along with corresponding balances and other position-specific details.

## Usage

:::code-group

```ts twoslash [example.ts]
import { moonwellClient } from './client'

const marketUserPositions = await moonwellClient.getMorphoMarketUserPositions({ // [!code focus:3]
  userAddress: "0x0000000000000000000000000000000000000000",
});
```

## Errors

The promise rejects with a `ChainReadError` when the read fails on any requested chain, so a failed RPC never looks like an empty position list. `error.failures` lists each failed chain as `{ chainId, reason }` with the original error, `error.data` carries the positions from the chains that succeeded, and `error.source` is `"getMorphoMarketUserPositions"`. The failure is not additionally reported through the client's `onError` callback. Chains without the relevant deployment are skipped, and an account with no positions resolves normally.

## Parameters

### userAddress

- **Type:** `Address`

The user address to get the market user positions for.

```ts twoslash
// [!include ~/snippets/moonClient.ts]
// ---cut---
const marketUserPositions = await moonwellClient.getMorphoMarketUserPositions({
  userAddress: "0x0000000000000000000000000000000000000000", // [!code focus]
});
```

### chainId (optional)

- **Type:** `number`

The chain ID to get the market user positions for.

```ts twoslash
// [!include ~/snippets/moonClient.ts]
// ---cut---
const marketUserPositions = await moonwellClient.getMorphoMarketUserPositions({

});
```
