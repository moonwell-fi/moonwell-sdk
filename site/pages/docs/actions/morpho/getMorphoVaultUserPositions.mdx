# getMorphoVaultUserPositions

Retrieves all active Moonwell Morpho Vault positions for a specific user address. This function returns detailed information about a user's deposits, including the amount deposited, current value, and any accrued rewards across all Moonwell Morpho Vaults they participate in.

## Usage

:::code-group

```ts twoslash [example.ts]
import { moonwellClient } from './client'

const vaultUserPositions = await moonwellClient.getMorphoVaultUserPositions({ // [!code focus:3]
  userAddress: "0x0000000000000000000000000000000000000000",
}); // [!code focus]
```

## Errors

The promise rejects when the read fails on any requested chain, so a failed RPC never looks like an empty position list. Each chain failure is first reported through the client's `onError` callback with `{ source: "getMorphoVaultUserPositions", chainId }`. A single failing chain rethrows the original error; several failing chains reject with an `AggregateError`. Chains without the relevant deployment are skipped, and an account with no positions resolves normally.

## Parameters

- **Type:** `Address`

The address of the user to get the positions for.


The chain ID to get the vault for.
