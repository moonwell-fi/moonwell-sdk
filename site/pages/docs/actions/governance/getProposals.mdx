# getProposals

Returns all governance proposals from the Moonwell protocol. This includes both active and historical proposals, allowing you to view the complete governance history. Each proposal contains details such as the proposal title, description, voting status, vote counts, and execution status.

## Usage

:::code-group

```ts twoslash [example.ts]
import { moonwellClient } from './client'

const proposals = await moonwellClient.getProposals(); // [!code focus]
```

## Parameters

### chainId (optional)

- **Type:** `number`

The chain ID to get the proposals for.

```ts twoslash
// [!include ~/snippets/moonClient.ts]
// ---cut---
const proposals = await moonwellClient.getProposals({
  chainId: 1284 // [!code focus]
})
```

<OptionalNetworkParameterInfo />

### network (optional)

- **Type:** `string`

The network to get the proposals for.

```ts twoslash
// [!include ~/snippets/moonClient.ts]
// ---cut---
import { ethereum } from "@moonwell-fi/moonwell-sdk/environments";

const proposals = await moonwellClient.getProposals<typeof ethereum>({
  network: "ethereum" // [!code focus]
})
```

### proposalChainIds (optional)

- **Type:** `number[]`
- **Default:** `[1, 1284, 1285]`

Governance chains to fetch proposals from: `1` (Ethereum, active), `1284` (Moonbeam archive) and `1285` (Moonriver archive). The archives account for almost all of the payload, so a view that only shows recent proposals can request `[1]` and load the archives separately when it needs them.

```ts twoslash
// [!include ~/snippets/moonClient.ts]
// ---cut---
const proposals = await moonwellClient.getProposals({
  proposalChainIds: [1] // [!code focus]
})
```
